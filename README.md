# ブラウザ上で解析する、csvから文章を解析し危険度を分析する
### 起動方法
htmlだけを実行
APIキー入力欄へAPIキーを入力

### v3とmultiモデルの違い
v3はGoogle Gemini 2.0 Flashで起動
multiモデルは2.0flashの他、1.5を選択できる
（Gemini更新後はご自由に書き換えをして継続利用ください）

### できること
自由記述式アンケートから生徒・児童の危険度を読み取る
SOSを求めていると思われるワードをタグ化

### 開発ツール
claude

### 開発経緯
最近はクラス編成の参考にアンケートを取ると聞いて、回収式ではなくGoogleフォームでのアンケート作成とその後のスプレッドシート化での整理をした後の自由記述部分の読み取りをAIですることで、SOSの度合いを判定し、またタグ化することで個人・クラスの問題のふたつの側面から分析をする簡易ツールを作成し、生徒の想いを視覚化することで問題解決への糸口になればとの思いで作成しました。すべては自身がまだ「いじめ」の言葉のない時代にいじめ不登校児であり、子どもが「いじめ被害者」として苦しんだ経験から作成いたしました。
